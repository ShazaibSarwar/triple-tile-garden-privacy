# Triple Tile Garden – Privacy Policy

Privacy policy for the Triple Tile Garden Android game, intended for GitHub Pages at:

https://shazaibsarwar.github.io/triple-tile-garden-privacy/

Contact: info.shasar@gmail.com

## Publishing

1. Create a GitHub repository named `triple-tile-garden-privacy`.
2. From this folder, initialize Git, commit the files, and push to
   `https://github.com/ShazaibSarwar/triple-tile-garden-privacy.git`.
3. In the repository settings, enable GitHub Pages with GitHub Actions as the source.
4. Add the published URL to AdMob Privacy & messaging and Google Play Console.

The included workflow deploys the static page whenever `main` is updated.
